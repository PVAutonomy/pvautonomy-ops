# PVAutonomy

[![HACS Custom](https://img.shields.io/badge/HACS-Custom-orange.svg)](https://hacs.xyz/)
[![License](https://img.shields.io/github/license/PVAutonomy/pvautonomy-ops)](LICENSE)

PVAutonomy is a Home Assistant integration for a DFRobot Edge101 controller
(DFR0886) that reads and controls a Growatt inverter over RS485/Modbus. Its
setup wizard generates the ESPHome configuration for the controller. You build
and flash the firmware yourself with ESPHome, using your own credentials; the
integration then adopts the running controller and creates a dashboard for it.

## Status

This is an **experimental Community Alpha** for technically capable Home
Assistant users.

- It comes **without warranty** and **without any support commitment**.
- It makes **no security, conformity or certification claim**.
- The internal security self-assessment `SEC-GATE-01` is **BLOCKED**, and
  **no security assurance is given**.
- It ships source code only: no firmware binary, no onboarding image, no
  installer. You build and flash the firmware yourself with ESPHome, using your
  own credentials.

## Tested stand

- **Growatt SPH10K** on a DFRobot Edge101 (DFR0886) in a bench setup with a
  real inverter: controller firmware generated by this integration's
  configuration generator (tier `extended`), built with ESPHome 2026.8.2 and
  flashed on 2026-09-22. This is bench validation: live validation of this
  stand in an installation is still pending, and not every function has been
  verified on hardware.
- **Growatt MIC600:** supported by the generator (tier `standard`); not
  validated on hardware at this stand.

## Requirements

- A DFRobot Edge101 (DFR0886) and a Growatt SPH10K or MIC600.
- Home Assistant, and ESPHome **2026.8.0 or newer**: the ESPHome Device
  Builder add-on or the ESPHome command-line tool.
- A USB data cable for the first flash, and a 2.4 GHz Wi-Fi network.

The complete list is in the installation guide.
